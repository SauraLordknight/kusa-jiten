# kusa事典

kusaで語られるネームド、用語、出来事、文化を整理する非公式事典です。

## 公開について

このサイトは静的なHTML・CSS・JavaScriptと同梱の効果音で構成しています。外部スクリプトは読み込まず、検索・草ガチャ・草パチの抽選はブラウザ内で行います。持ち球・草・ガチャ券・取得カードは利用中のブラウザに保存されます。草パチの24時間ランキングは、遊技記録の一部とランダムな識別子をCloudflareへ送って集計します。

公開用のトップページは `index.html` です。以前共有した `kusa_named_directory_final.html` も同じ内容にしているため、どちらのURLでも開けます。更新時は両方を同期してください。

公開前に `node verify-release.js` を実行してください。両HTMLの一致、カード枠とモード効果音の配置、既存のガチャ取得記録と草パチの持ち球を読み継げることを確認します。保存キー `kusa-jiten-gacha-v1`、`kusaPachiProfilesV1`、`kusaPachiRewardsV1` は移行処理なしで変更しないでください。ランキングAPIのコードと集計方法は `ranking/` に記録しています。

## セキュリティ上の制約

GitHub Pagesの静的サイトなので、ガチャのカード一覧・排出率・当たり判定は配信されたHTMLとJavaScriptから調べられます。持ち球・草・ガチャ券・取得カードは各自のブラウザに保存され、開発者ツールやバックアップファイルで書き換えられます。画面上では未取得カードを伏せていますが、ソースコードまで秘密にしたり、ブラウザ内の改変を防いだりはできません。難読化やブラウザ内の署名だけで解決したと判断しないでください。

現在のランキングはブラウザが計算した遊技記録を送信する方式です。入力検証と送信制限はありますが、改変されたブラウザから架空の記録を送る行為は完全には防げません。競争性の高い企画や換金可能な特典、真正な取得証明に使う場合は、抽選と残高の増減をサーバー側で管理してください。

kusaの運営者とは関係ありません。掲載内容の訂正・削除依頼は、サイト内の要望BOXからお知らせください。
